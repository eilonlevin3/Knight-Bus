# ADR-0001: An installable web app (PWA) instead of a store app

**Status:** Accepted · 2026-10-09

## Context

We want Knight Bus on a phone home screen soon, with one codebase, and without app-store
review, fees or native toolchains.

## Decision

Build a **Progressive Web App**: a normal website plus

- a **web app manifest** ([manifest.webmanifest](../../manifest.webmanifest)) for name, icon,
  colors and full-screen (`standalone`) mode, which lets the browser offer *Install / Add to
  Home Screen*;
- a **service worker** ([sw.js](../../sw.js)) so the app opens offline and starts fast;
- **HTTPS hosting** (GitHub Pages), which phones require for both of the above and for GPS.

## Consequences

- Works on Android and iPhone from one codebase. Updates ship by pushing to `main`.
- iOS limits: you install only from Safari, and the device may clear storage after weeks
  of non-use (the app then downloads the city data again).
- If we later want store listings, the same site can be wrapped with Capacitor (iOS and
  Android) or a Trusted Web Activity (Android) without a rewrite.
